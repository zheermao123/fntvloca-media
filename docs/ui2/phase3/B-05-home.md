# B-05 首页数据准确性

日期：2026-11-15
分支：`feature/ui2-phase3`

## 实现

- 分类计数改用 `library:catalog` 的真实 `total`（每分类 `limit=1`），不再以 600 上限推断；移除“capped”估算展示。
- 最近添加继续使用 `limit=12`，不拉取全库。
- 新增“继续观看”区块：复用既有 `library:continue`，展示电影/剧集续播卡片，路由到详情/季详情；隐私模式首页不请求/不展示。
- 首页并行请求分类计数、最近添加、继续观看；异步请求序号保护，切换/卸载不写入过期结果。

## 测试与证据

- 大库 E2E（17k 电影 + 500 剧 fixture，隔离 profile）：首页“继续观看”出现（种子进度），随后分页验收通过。
- 真实库回归 p207：首页/媒体库/详情/搜索/源/任务无 console error。
- 总测试 271/271。

## 已知限制

- 首页仍发起 4 次分类查询（每次 `limit=1`，但主进程会做一次计数/页查询）；后续可评估专用 counts 接口。
- 继续观看限制来自既有 `CONTINUE_LIST_LIMIT`，不新增加载更多。
