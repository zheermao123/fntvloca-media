# B-02 任务中心完整化

日期：2026-11-15
分支：`feature/ui2-phase3`

## 实现

- 任务页新增**本次会话任务历史**（最多 20 条）：类型、开始时间、进行中/已完成/失败、真实结果摘要；失败条目提供“重试”（扫描/刮削均幂等安全）。
- 进入页面时继续读取主进程 `library:scrape-status`（running + 最近一次摘要）；主进程刮削运行中时明确提示“离开页面后无法恢复百分比”。
- 扫描仍无状态查询接口：不伪造“运行中/进度”；离页后重进显示空闲，但重复触发会被主进程单飞守卫拒绝。
- 离页/卸载清理进度订阅与长等待监听；重复点击有同步 in-flight 锁。
- 纯函数：`addSessionTask`/`finishSessionTask`/`taskKindLabel`/`taskStatusLabel`/`formatTaskTime`。

## 测试

- `tests/ui2SourcesTasks.test.cjs` 新增 2 项会话历史行为测试（顺序、完成状态、标签、上限）。
- `tests/ui2TasksService.test.cjs` 5 项：触发、取消、done 汇总、进度订阅/退订、状态查询。
- 总测试 271/271。

## 已知限制

- 历史仅本次页面会话，不持久化；主进程不提供任务历史/唯一任务 ID（需 L2 才可跨页/重启恢复）。
- 扫描无进度/状态 API；不展示伪造百分比。
- 真正的“取消主进程任务”不在本阶段（未新增协议）。
