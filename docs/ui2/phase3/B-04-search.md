# B-04 全局搜索完善

日期：2026-11-15
分支：`feature/ui2-phase3`

## 实现

- 保留 Cmd/Ctrl+K 与弹层；新增分类过滤（全部/电影/剧集/动漫/其他视频），基于真实 `library:catalog` 的 source category。
- 使用 `queryCatalogPage` 返回真实 `total`：显示“匹配 N 条，当前显示前 M 条”（上限 50）。
- 最近搜索仅保存在弹层组件内存（关闭即清除，不持久化）；隐私模式切换时重置分类过滤。
- 空结果/加载/错误/清除状态；错误重试不再篡改关键词；Escape 关闭；结果卡片可 Tab 聚焦。
- 文案如实：仅标题（含剧集名），不支持文件名/模糊/全文搜索。

## 测试与证据

- 后端分类过滤新增测试：`libraryCatalogPagination.test.cjs`（movie/tv/anime 分区 total 正确）。

## 已知限制

- 文件名搜索仍不受后端支持，未做假入口。
- 最近搜索不跨弹层/重启保留（出于隐私与无持久化存储设计）。
- 分类过滤 UI 的独立自动化未加入当前大库脚本（后端分区与真实弹层已覆盖）；列为后续 C 回归补测项。
